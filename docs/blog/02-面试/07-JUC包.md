# JUC包
## 1、juc常用工具类

1. ExecutorService 线程池相关工具

2. Lock锁相关工具，ReentrantLock重入锁，支持重入性，表示能够对共享资源能够重复加锁，即当前线程获取该锁再次获取不会被阻塞。

3. 并发集合类，ConcurrentHashMap

4. 同步工具类，CountDownLatch等

5. 原子类

## 2、原子类Atomic是怎么保存原子性的

Java原子类保证原子性主要是基于CAS操作，它是一种无锁的算法，包含三个操作数：内存位置、预期原值，新值。

CAS操作时，会先比较内存位置处的值是否等于预期原址，如果相对，则将该位置的值更新为新值，如果不相等，就不更新。

## 3、BlockingQueue阻塞队列

是一个支持两个附加操作的队列。

这两个附加的操作是：在队列为空时，获取元素的线程会等待队列变为非空。当队列满时，存储元素的

线程会等待队列可用。

阻塞队列常用于生产者和消费者的场景，生产者是往队列里添加元素的线程，消费者是从队列里拿元素

的线程。阻塞队列就是生产者存放元素的容器，而消费者也只从容器里拿元素。
