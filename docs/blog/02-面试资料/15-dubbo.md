# dubbo
## 1、Dubbo的实现原理和架构

通信：默认使用netty的NIO模型，实现高并发网络读写，可进行客户端和服务端双向数据传输，

支持Dubbo传输协议，将Java对象序列化为二进制传输，服务端再反序列化。

服务暴露：Dubbo读取配置文件或者注解，获取服务的相关配置信息（接口、实现类、协议、端口等）；

将服务的元数据信息注册到ZK，服务启动，向ZK发送注册请求

服务引用：消费者启动，从ZK获取服务信息列表缓存到本地；

Dubbo会为消费者生成一个代理对象，封装和服务提供者之间的通信细节。

负载均衡：提供多种算法，随机、轮询、最少活跃等。并且根据服务提供者的运行状态，如响应时间、并发数等，动态调整负载均衡策略。

## 2、Dubbo的负载均衡策略

1. 随机算法，按权重设置随机

2. 轮询算法，按权重设置轮询

3. 最少活跃算法

4. 一致性hash算法，hash相同的分配同一个服务
