# sentinel
## 1、sentinel是什么

sentinel是一种实现流量控制、熔断降级的解决方案，是阿里开源的一个框架。

## 2、sentinel主要功能

1. 熔断机制

2. 降级机制

3. 高可用机制

4. 自适应控制

## 3、sentinel基本组件

（1）资源

SphU\.entry和entry\.exit\(\)将资源包围

资源注解@SentinelResource，注解参数：

value：资源名

blockHandler：限流后的处理方法，BlockException异常触发

fallback：所有异常触发后的处理方法

（2）规则

SystemRule硬编码定义规则或者通过客户端配置规则

（3）上下文

（4）插槽

Sentinel在内部创建了一个责任链，责任链是由一系列插槽接口的实现类组成的，每个插槽对象负责不同的功能，外部请求想要访问资源需要责任链层层校验和处理。每个Slot 需要执行 （例如配置过降级规则DegradeSlot）则处理，不需要执行则交给下一个Slot 。每一个Slot如果处理失败或者/如果校验失败，会抛出BlockException异常。

## 5、滑动窗口算法实现原理

1\.将整个时间范围划分为多个固定大小的时间窗口，这些时间窗口随着时间流动依次滑动。

2\.为每个时间窗口配置一个计数器，记录这个时间窗口内的请求数量。

3\.当有请求进入时，将其计入当前时间窗口的计数器。

4\.定期滑动时间窗口，将过期的时间窗口删除，新增新的时间窗口。

5\.当有请求访问时，会去判断当前时间窗口的请求数是否已经达到了阈值，如果是的话，会拒绝或者执行降级策略。

6\.定期重置过期时间窗口的计数器。
