# 写好第一篇技术文章

## 目录约定

```text
docs/
  index.md                 # 根路径自动跳到本页
  blog/
    01-首页/               # 数字前缀决定侧边栏分组顺序
      01-写好第一篇技术文章.md
      02-关于本站.md
    02-面试/
      01-自我介绍和项目介绍.md
    03-其他/
      01-占位说明.md
```

文件夹、文章都建议用 **`数字-名称`**，数字越小越靠前。

## 新增文章

```text
docs/blog/02-面试/29-新主题.md
```

## 新增分组

```text
docs/blog/04-前端/
  01-第一篇.md
```

## 本地预览

```bash
npm run docs:dev
```

根路径会跳到本页；请务必带上 base 前缀访问：  
http://localhost:5173/interview-blog/  
或  
http://localhost:5173/interview-blog/blog/01-首页/01-写好第一篇技术文章
